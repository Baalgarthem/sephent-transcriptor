## Resumen de Tokens y Variables
- **Paleta Oficial:** Negro Obsidiana (`#121212`), Carbón Mate (`#1C1C1A`), Marfil Pergamino (`#FBFBF9`), Blanco Puro (`#FFFFFF`), Gris Grafito (`#595852`), Taupe Arena (`#B5A795`), Verde Oliva Bosque (`#2D5A3D`), Ámbar Siena Tostado (`#8C5A2B`).
- **Pila Tipográfica:** Serif clásico (`Georgia, "Times New Roman", serif`) para títulos editoriales; Sans-serif moderna (`system-ui, "Segoe UI", Roboto`) para controles y transcripciones; Monospace (`"Cascadia Code", "Consolas"`) para rutas y hashes.
