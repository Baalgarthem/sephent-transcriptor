# Insumos Pendientes (insumos-pendientes.md)

Registro de recursos, datos o elementos externos pendientes de suministrar para futuras fases:

- Ningún insumo pendiente para la fase actual de interfaz gráfica, detección de rutas oficiales y gestión de copias de seguridad antiduplicado.
- Para fases posteriores de empaquetado nativo final con instalador `.msi` o `.exe`, se requerirá tener instalado el toolchain de Rust (`rustc`, `cargo`) en el sistema Windows si el usuario decide compilar el binario nativo de Tauri.
