# Estudio de Factibilidad (factibilidad.md)

- **Factibilidad Técnica:** Plenamente viable mediante tecnologías web modernas (Web Crypto API, File System API, Vite, React) y backend de escritorio con Tauri / Node.
- **Factibilidad Operativa:** Interfaz accesible y pedagógica que guía al usuario paso a paso sin requerir comandos de consola.
- **Factibilidad Económica:** Software de código abierto con modelo de patrocinio comunitario vía donación PayPal.
